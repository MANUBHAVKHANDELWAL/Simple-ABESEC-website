#Simple ABES Engineering College Website

This is a simple website about ABES Engineering College, created as a student project using HTML and CSS.

## About the Project

The website provides basic information about ABES Engineering College, its branches, courses, fees, and other details.

## Features

- Welcome section
- ABES Engineering College image
- Branches section
- Course details table
- About ABES section
- Fee information
- Contacts page
- Courses page

## Technologies Used

- HTML
- CSS

## Courses Included

- B.Tech
- BCA
- MCA
- AI/ML
- EC

## Pages

### Home
The main page contains information about ABES Engineering College.

### Courses
Contains information about the courses offered.

### Contacts
Contains contact information.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `doc.html` in a web browser.

## Project Purpose

This project was created to practice HTML and CSS concepts such as:

- Tables
- Images
- Links
- Headings
- Paragraphs
- CSS classes
- Background colors
- Text formatting
- Marquee
